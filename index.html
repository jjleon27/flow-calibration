Flow calibration (gravimetric)

Delivered flow depends on two things: how far the drive head travels (pump mechanics) and the syringe bore you program. Weighing the water measures only their product, so calibrate them in order — do it backwards and a mechanics error hides inside a wrong "effective diameter":

  1. Pump mechanics first (Step 1) — so the drive head moves the true distance.
  2. Syringe diameter second (Steps 2–5) — the balance then corrects the bore alone.

The gravimetric part needs only an analytical balance — water weighs ~1 g/mL, so 1 mg ≈ 1 µL:

Q_real = mass / (ρ_water · time)
D_real = D₀ · √(Q_real / Q_set)

If the balance reads more than programmed → the syringe is wider than you told the pump → increase the diameter. A web calculator (and calibrate.py) do the math for both steps — the mechanics (Step 1) and the diameter (Steps 2–5); you just type the numbers you measured.

Equipment

  • Analytical balance, 1 mg (0.001 g); 0.1 mg is even better.
  • Dial indicator or digital caliper (0.01 mm) — to measure drive-head travel (Step 1).
  • Syringe under test, filled with bubble-free distilled water.
  • Parafilm + a small receiving tube (e.g. Eppendorf).
  • Tweezers/tongs for handling calibration weights (skin oil weighs enough to matter).
  • The syringe pump.

Step 0 — Calibrate the balance (once)

  1. Place it on a stable, level table (centre the bubble with the feet); no drafts, sun or vibration. Warm it up for ≥ 1 hour powered on.
  2. Empty pan, reading 0.0. Enter external calibration (on CGOLDENWALL/JoanLab HZ-type balances: Set → menu → e-cal; it requests a standard weight, e.g. cal-200 = 200 g).
  3. Place the exact standard weight with tongs, wait, remove when prompted → returns to 0.0.
  4. Verify: place a known weight (e.g. 100 g) and check it reads correctly.

Step 1 — Calibrate the pump mechanics (plunger travel)

⚙️ First, match the software to this pump. gearbox, rod (lead screw) and microstep are stored per pump and must match the physical hardware. Re-check them whenever you swap pumps, or move the controller between a geared and an ungeared pump. On this lab's pumps: ungeared → gearbox 1:1; geared → gearbox 100:1; both use the T8 1-star (2 mm) rod and microstep 1/8, with the same syringe diameter. A wrong gearbox shows up below as a clean ~25× / 100× travel error, a wrong rod as ~4× (see the troubleshooting table).

➡️ Open the web calculator — Step 1: enter flow, time, diameter and start/end readings → expected travel, error, corrected THREADROD.

First check the mechanics on their own: does the drive head move the distance it should? This is the displacement method of EURAMET CG-27 §4.3.3 (lab version: laser interferometer; workshop version: a caliper or dial indicator — exactly how a 3D-printer axis's steps/mm is calibrated).

This pump has no "move N mm" command — you set a diameter and a flow and let it run, so the travel comes from flow × time:

  1. Mount a caliper or dial indicator against the drive head / carriage and zero it. Keep a syringe mounted, dispensing to waste, as in a normal run (metrology labs use a rigid glass/steel syringe with the mirror on the pusher block; a normal syringe is fine here).
  2. Set the diameter D and a flow Q and run for a few minutes — longer = smaller % error (set_diameter, set_flow, set_state in pump_comm.py). The commanded travel is L_set = Q · t / (π · (D/2)²) e.g. D = 9.05 mm, Q = 3000 µL/h, t = 15 min → L_set ≈ 11.7 mm (keep units consistent; the pump's max is 6000 µL/h, and the gearbox does not change this travel).
  3. Read the actual travel L_real. Repeat 2–3× and average to shrink the reading scatter.
  4. If L_real ≈ L_set, the mechanics are good. Otherwise correct the lead-screw pitch (THREADROD, via set_threadrod): threadrod_corr = threadrod × (L_real / L_set). The firmware derives steps/mm from microstep, gearbox and threadrod, so threadrod is the knob to trim.

No caliper? Even a ruler works — just run longer so the move is ~50–100 mm and the coarser reading stays a small fraction of the distance.

If L_real comes out very different from L_set — a clean factor points to a wrong setting; a small % is just real tolerance or reading noise:

L_real vs L_set Likely cause Fix
~25× or ~100× off Gearbox set wrong set it to the pump's real ratio (1:1 / 25:1 / 100:1)
~4× off Rod wrong (1-star = 2 mm vs 4-star = 8 mm) set rod to match the physical lead screw
~2× / 4× / 8× off, gearbox & rod correct Microstep mismatch (driver ≠ firmware) check microstep — over UART it's normally self-consistent, so this is rare
small (< ~2 %) lead-screw pitch tolerance or reading noise tiny THREADROD tweak, or repeat 2–3× and average
erratic / not repeatable loose coupling grub screw, binding, or missed steps tighten the coupling, check for binding, lower speed / raise motor current

The web calculator flags these automatically — if the error is large it tells you which parameter to check.

Step 2 — Prepare the gravimetric run

  1. Fill the syringe, purge all air (a single bubble ruins a run). Mount it in the pump.
  2. Program the nominal diameter D₀ (caliper the inner bore, or use the syringe spec) and the target flow Q_set.
  3. Let the pump drip into any waste tube until the flow is steady — we use 5 min; the first minutes clear residual bubbles and let the mechanics settle.

Step 3 — Collect the output, weighed (timed collection)

Prepare the collection tube first: close the empty Eppendorf, seal the top with parafilm, pierce a small hole with the sharp tip of scissors (just big enough for the capillary — keeps evaporation low), and stand it on a small, very light base (we cut one from packing foam — negligible mass, keeps the round-bottom tube upright on the pan). Weigh it in this final state (tube + parafilm + hole + foam base) → m_empty, or tare to zero.

Then collect, without stopping the flow: with the flow already steady, move the capillary from the waste tube into the collection tube through the parafilm hole, and start the stopwatch at that instant. Collect for an exactly timed interval t. Move the capillary out, press the parafilm closed over the hole, and weigh immediately → m_full. Δm = m_full − m_empty.


1 — Caliper the bore to get the nominal diameter D₀
2 — Seal the tube top with parafilm
3 — Pierce a small hole with a scissor tip
4 — Insert the capillary through the hole

Aim for Δm ≥ 100 mg (e.g. 10 min at 1000 µL/h ≈ 167 mg → <1 % uncertainty at 1 mg).

Step 4 — Compute the corrected diameter

➡️ Open the web calculator — Steps 2–5: type the weighed values, get the corrected diameter.

python3 calibrate.py --d0 8.94 --qset 1000 --mass 170.5 --minutes 10 --temp 20
#   flow real (balance): 1024.8 uL/h  (+2.5 %)
#   CORRECTED DIAMETER : 9.05 mm   <- enter this on the pump

Enter D_real on the pump. Repeat one point to confirm Q_real ≈ Q_set.

Step 5 — Verify linearity

Repeat at at least 3 flow points — the ones you'll actually use — with 3 measurements each (e.g. 500 / 1000 / 2000 µL/h ×3), following EURAMET CG-27. The 3 repeats give the repeatability; if all points return the same D_real, the calibration is solid and flow-independent.

Background (optional)

Delivered flow = drive-head speed × syringe cross-section. Gravimetry sees only the product, so a wrong lead-screw pitch looks exactly like a wrong bore — that's why Step 1 (travel) comes before Step 4 (bore). Many open-hardware pumps skip the split and fold both into one "effective diameter" per pump (Wijnen & Pearce, 2014): accurate flow, but you no longer know which part was off.

Mechanism cycle. A lead-screw pump's flow has a slow ripple at the screw's turn period (EURAMET CG-27). Collect over ≥ 2 full turns to average it out — it's expected, not a bubble.

Practical tips (what ruins a run)

  • Evaporation: at 1000 µL/h an open tube loses ~1 mg/min — always parafilm, and weigh immediately after capping.
  • Weights with tongs, never fingers.
  • Exclude the first ~5 min of each run (stabilization + bubble clearing).
  • Record water temperature; the tool adjusts density (20 °C → 0.99821 g/mL). ±2 °C is negligible (<0.1 %).
  • Bubbles: purge before, and if the output suddenly spikes/dips erratically, there is air in the line — stop and purge.

Optional: cross-check with a flow sensor (higher precision)

The balance fixes the diameter. If you also have an in-line flow sensor, the same runs let you check — and calibrate — the sensor against the balance (ground truth), then use the sensor as a continuous flow reference without weighing every time. calibrate.py reports the sensor factor if you pass --sensor-ulh <reading>.

For the flow-sensor hardware, firmware and high-rate acquisition, see the Rio controller: ➡️ wenzel-lab/rio-controller (pressure/flow module).
